This is the documentation index. It is built with [Fumadocs](https://fumadocs.dev) and TanStack Start. The site and its optional framework previews run on the same web domain.

## What's inside

- **Dashboard** — an overview of your todos
- **Todos** — create and manage tasks
- **Form blocks** — reusable form components

## Writing docs

Every `.mdx` file under `apps/docs/content/docs` becomes a page. Frontmatter controls its title and description.
