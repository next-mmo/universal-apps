The same Apple-inspired design system that powers the DOM components runs on **React Native Web (RNW)** via `@package/ui-native` — hand-built RN primitives (`Pressable`/`View`/`Text`) styled with **Uniwind**, which compiles Tailwind v4 classes for React Native at build time. No Metro, no Expo required: the playground is a plain Vite app.

## How it fits the adapter architecture

The repo's cross-framework recipe applies unchanged:

| Layer | DOM (React) | Native (RNW) |
| ----- | ----------- | ------------ |
| Tokens | `packages/ui/src/styles/tokens.css` (CSS custom properties) | **same file**, imported into the playground CSS entry |
| Components | `packages/ui` (Radix + Tailwind classes) | `packages/ui-native` (RN primitives + Uniwind `className`) |
| Playground | `apps/docs/previews/uniwind` (built on demand at `/previews/uniwind/`) | `apps/native-playground` (`vite-plugin-rnw` + `@tailwindcss/vite` + `uniwind/vite`, port 1453) |

## Uniwind styling

`apps/docs/previews/uniwind/vite.config.ts` chains `rnw()` (React Native Web resolution + fixes), `tailwindcss()`, and `uniwind({ cssEntryFile: './src/index.css' })`. Its CSS entry imports `tailwindcss`, `uniwind`, and the shared tokens, and scans `packages/ui-native/src` via `@source`. The preview is built separately and fetched only when selected; it runs in the browser through React Native Web, not on an iOS or Android device.

Components mirror the DOM siblings' class strings 1:1; color utilities (`bg-primary`, `text-muted-foreground`, `dark:bg-card`, …) resolve the tokens.css variables. Because RN has no style inheritance, container utilities sit on the primitive and text color/size utilities on the inner `Text` — see the `variantClasses` maps in `packages/ui-native/src/components/ui/*`. Web-only utilities (hover, focus rings) are elided; pressed feedback uses `active:`.

Dark mode is uniwind-managed: `Uniwind.setTheme('dark' | 'light')` flips the theme and uniwind keeps `<html class="dark">` in sync, so the tokens.css variables and every `dark:` variant switch together. The initial theme follows the system (uniwind's `adaptiveThemes` default). The toggle in `apps/native-playground/src/playground.tsx` is the reference implementation.

`packages/ui/src/tokens.ts` (the JS palette/shadow mirror) stays in the repo for future real-native Metro targets, but ui-native no longer imports it.

## Running the playground

```bash
pnpm dev:native   # standalone playground → http://localhost:1453
```

Renders every ui-native component (buttons in all variants/sizes, badges, a form card with Input + Switch, separators) with a working light/dark toggle.

## Component parity

| Primitive | Status | Notes |
| --------- | ------ |-------|
| Button | ✅ | All 6 variants + 4 sizes; same variant classes as the DOM version; `Pressable` |
| Badge | ✅ | 6 variants with the DOM tinted fills (`bg-primary/12`, `bg-green/15`, …) |
| Card | ✅ | All five slots (`Card`…`CardFooter`); `shadow-[var(--shadow-card)]` |
| Input | ✅ | Wraps RN `TextInput`; `invalid` prop mirrors `aria-invalid`; placeholder color via uniwind `useCSSVariable` |
| Switch | ✅ | Radix-style `checked`/`onCheckedChange` API; green-on track like the DOM version |
| Separator | ✅ | Horizontal/vertical hairline |
| Label | ✅ | Text port; pairs with `InputLabel` for form fields |
| Checkbox | ✅ | `checked`/`onCheckedChange` API; ✓ glyph indicator |
| Skeleton | ✅ | RN `Animated` pulse loop (Uniwind has no keyframes) |
| Textarea | ✅ | Multiline `TextInput` in a bordered box; token-aware placeholder |
| Table | ✅ | Rows become flex Views in a horizontal `ScrollView` |
| Accordion | ✅ | Context-based single-open list; `defaultValue` uncontrolled mode |
| Tabs | ✅ | Segmented `TabsList` + content panel; controlled or `defaultValue` |
| Tooltip | ✅ | Single `content`-prop API: press-and-hold shows the bubble |
| Dialog | ✅ | RN `Modal` card over a dimmed backdrop; `open`/`onOpenChange` |
| Dropdown Menu | ✅ | `Modal` action sheet; items, labels, separators, checkbox items |
| Popover | ✅ | `Modal` panel with arbitrary content; backdrop-press dismiss |
| Select | ✅ | `Modal` sheet; `value`/`onValueChange` with `SelectValue`/`SelectItem` markers |

RN has no portals or Radix, so the overlay components (Dialog, Dropdown Menu, Popover, Select) render via RN's `Modal` as centered sheets over a dimmed backdrop instead of anchored popups — the prop APIs stay DOM-compatible. lucide icons are replaced with text glyphs (✓ ⌄ ×) to avoid a `react-native-svg` dependency, and animations that rely on CSS keyframes (`animate-pulse`) use RN's `Animated` instead.

## Porting recipe (and the CLI)

New native components follow the DOM siblings' prop APIs so the two stay swappable behind a shared contract:

```bash
pnpm scaffold add native <kebab-name>   # emits from templates/native/, wires docs
```

The scaffold's `native` target writes to `packages/ui-native/src/components/ui/` and rewrites `@/lib/cn` → `@package/ui/cn`. Then port the real implementation from the DOM component: the Tailwind classes carry over as-is (Uniwind compiles them for RN), replace Radix behavior with RN primitives, and split text color/size utilities onto the `Text` node.
