## Anatomy

```tsx
import { ProFilterToolbar } from '@package/pro/filter-toolbar';

export function Example() {
  return (
    <ProFilterToolbar
      fields={[
        { name: 'query', label: 'Search Keyword', type: 'text', placeholder: 'Search users...' },
        {
          name: 'role',
          label: 'Role',
          type: 'select',
          options: [
            { label: 'Admin', value: 'admin' },
            { label: 'User', value: 'user' },
            { label: 'Guest', value: 'guest' },
          ],
        },
        { name: 'date', label: 'Registered Date', type: 'date' },
        { name: 'window', label: 'Billing Period', type: 'date-range' },
      ]}
      onFilter={(filters) => {
        console.log('Applied filters:', filters);
      }}
      onReset={() => {
        console.log('Filters reset');
      }}
    />
  );
}
```

---

## Field types

`type` is one of `text`, `select`, `date`, or `date-range`. A `date-range` field renders a
`DateRangePicker` and stores a `[Date, Date]` tuple in the emitted filters; a value that is not a
two-`Date` tuple — for example two strings from a query string — is ignored and the control falls back
to its placeholder instead of throwing.
