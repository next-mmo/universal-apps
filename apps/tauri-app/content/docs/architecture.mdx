## Workspace layout

| Path | Purpose |
| ---- | ------- |
| `apps/tauri-app` | The Tauri + React application |
| `packages/core` | Shared business logic |
| `packages/ui` | Shared UI components (shadcn-based) |
| `packages/pro` | Pro layout components |
| `packages/tauri-api` | Typed Tauri command bindings |

## Tech stack

- **Tauri 2** for the native shell (desktop & Android)
- **TanStack Router** for client-side routing
- **TanStack Query** for data fetching
- **Tailwind CSS v4** for styling
- **Fumadocs** for this documentation section

## Data flow

Todos live in `@package/core` as plain services. The app exposes them through TanStack Query hooks in `src/lib/todo-queries.ts`, and pages consume those hooks — no global state library involved.
