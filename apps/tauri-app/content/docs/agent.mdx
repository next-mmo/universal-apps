Read the root `AGENTS.md` first. It is the authoritative operating contract. This page routes repository work; API facts come from the checked-in catalog and focused component pages.

## Start with one command

```bash
pnpm agent find table --framework vue
pnpm agent inspect ProDataTable      # by exported symbol
pnpm agent inspect block.data-table  # or by catalog id
pnpm agent recipe crud-page --framework react
pnpm agent check --changed
```

`agent/catalog.json` is the machine-readable capability source. `/llms.txt` is the standard documentation index, `/llms-full.txt` is the optional complete bundle, and `/docs/<path>.md` exposes clean Markdown for one page. Prefer the index plus one relevant page over the full bundle.

## Workspace map

| Path | Responsibility |
| --- | --- |
| `packages/pro-core` | Framework-free form, table, and query contracts |
| `packages/ui` | React DOM primitives and CSS design tokens |
| `packages/pro` | React feature blocks |
| `packages/pro-vue` | Vue feature-block adapters |
| `packages/pro-svelte` | Svelte feature-block adapters |
| `packages/ui-native` | React Native/Web primitives styled with Uniwind (Tailwind classes, shared tokens.css) |
| `packages/tauri-api` | Typed Tauri operations and browser fallbacks |
| `packages/core` | Shared application domain logic |
| `packages/cli` | Agent discovery, verification, and scaffold commands |
| `apps/*-playground` | Compileable integration examples for each framework |

## Hard conventions

1. Use full cross-package file imports until stable subpath exports exist; do not add root barrel files.
2. Put framework-neutral contracts in `pro-core` before adapters.
3. Keep raw Tauri calls inside `tauri-api` and provide a browser fallback.
4. Register new Tailwind-scanned package sources in each consuming app stylesheet.
5. Add component/block docs and catalog metadata with the implementation.
6. Use shadcn patterns for primitives and TanStack engines for feature blocks.

## Safe scaffolding

```bash
pnpm scaffold list
pnpm scaffold add ui alert --dry-run
pnpm scaffold add ui alert
```

Only complete vendored templates are accepted by default. Unknown components fail without writing. `--allow-placeholder` is an explicit escape hatch and is not production-ready. Use `--no-install` to plan dependency changes separately and `--json` for machine-readable output.

## Documentation maintenance

Run `pnpm agent:docs` after documentation or catalog changes. `pnpm agent:docs:check` detects stale checked-in `llms.txt` artifacts without writing. The normal changed-scope verifier includes this check.

## Known operational details

- `pnpm dev` starts the browser frontend; `pnpm tauri dev` starts the native shell.
- Fumadocs type generation runs when the docs app starts or builds.
- Sidebar order comes from each folder's `meta.json`.
- `pnpm agent check --changed` selects affected framework builds and prints detailed output only on failure.
