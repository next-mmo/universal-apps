---
title: Getting Started
description: Set up the project locally and start developing.
---

## Prerequisites

- Node.js 20+
- pnpm 10+

## Install

```bash
pnpm install
```

## Run

```bash title="Run dev server"
pnpm dev
```

The app is served at `http://localhost:1420`.

## Build

```bash
pnpm build
```

For the web-only build without Tauri, use `pnpm build:web`.
