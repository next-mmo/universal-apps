A binary input that toggles a single value. Source: `packages/ui/src/components/ui/checkbox.tsx`, built on `@radix-ui/react-checkbox`.

## Import

```ts
import { Checkbox } from '@package/ui/checkbox';
```

## Usage

<CheckboxDemo />

```tsx
import { Checkbox } from '@package/ui/checkbox';
import { Label } from '@package/ui/label';

<div className='flex items-center gap-2'>
  <Checkbox id='pin' />
  <Label htmlFor='pin'>Pin to top</Label>
</div>
```

## API

| Prop | Values | Notes |
| ---- | ------ | ----- |
| `checked` | `boolean` \| `'indeterminate'` | Controlled state; use `defaultChecked` for uncontrolled. |
| `onCheckedChange` | `(checked) => void` | Change handler. |

All other props forward to the Radix primitive (`disabled`, `required`, …).
