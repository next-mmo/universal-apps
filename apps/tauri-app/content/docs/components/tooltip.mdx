A brief message on hover/focus. Source: `packages/ui/src/components/ui/tooltip.tsx`, built on `@radix-ui/react-tooltip`. The app wraps the router in `TooltipProvider` (see `src/main.tsx`).

## Import

```ts
import { Tooltip, TooltipContent, TooltipTrigger } from '@package/ui/src/components/ui/tooltip';
```

## Usage

<TooltipDemo />

```tsx
<Tooltip>
  <TooltipTrigger asChild>
    <Button variant='ghost' size='icon'><InfoIcon /></Button>
  </TooltipTrigger>
  <TooltipContent>More information</TooltipContent>
</Tooltip>
```

## API

`Tooltip` root, `TooltipTrigger` (hover/focus target), `TooltipContent` (`side`, `align`, `sideOffset`). Delay and dismiss behavior come from the provider (`delayDuration`, `skipDelayDuration`).
