A single-line text field. Source: `packages/ui/src/components/ui/input.tsx`.

## Import

```ts
import { Input } from '@package/ui/input';
```

## Usage

<InputDemo />

```tsx
import { Input } from '@package/ui/input';
import { Label } from '@package/ui/label';

<div className='grid gap-2'>
  <Label htmlFor='task'>Task</Label>
  <Input id='task' placeholder='What needs doing?' />
</div>
```

## API

A plain `<input>` — every native prop forwards (`type`, `value`, `onChange`, `disabled`, …). Validation styling: `aria-invalid` switches the border to destructive.
