## Anatomy

```tsx
import { toast, Toaster } from '@package/ui/toast';
import { Button } from '@package/ui/button';

export function Example() {
  return (
    <>
      <Button
        onClick={() =>
          toast.success('Record created', {
            description: 'Item has been added to your workspace.',
            action: { label: 'Undo', onClick: () => console.log('Undo') },
          })
        }
      >
        Show Toast
      </Button>

      {/* Render once at root layout */}
      <Toaster position="bottom-right" />
    </>
  );
}
```

## Key Features

- **Cross-Platform**: Zero-dependency GPU compositor transitions on Web; native driver springs on React Native.
- **Convenience Methods**: `toast()`, `toast.success()`, `toast.error()`, `toast.warning()`, `toast.info()`, `toast.dismiss()`.
- **Action Buttons**: Embedded callback buttons that automatically dismiss on press.
