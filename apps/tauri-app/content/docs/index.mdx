This is the documentation index. It is built with [Fumadocs](https://fumadocs.dev) running entirely client-side inside a Vite SPA — no server required, which makes it a good fit for Tauri.

## What's inside

- **Dashboard** — an overview of your todos
- **Todos** — create and manage tasks
- **Form blocks** — reusable form components

## Writing docs

Every `.mdx` file under `apps/tauri-app/content/docs` becomes a page. Frontmatter controls its title and description.
