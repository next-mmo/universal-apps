# Workflow — js-md-links

This example adopts ND Workflow. Work is classified by risk tier (low: docs and wording, medium: parsing/walk/exit codes, high: path policy and file-access safety), checkpointed in a task record under `docs/tasks/` before a pause or handover, and closed with a converge-check that matches every acceptance criterion against freshly observed evidence rather than intent. Verification is always the real command output — `node --test` plus at least one CLI smoke run — and failures are recorded as failures. The authoritative policy, including approval boundaries and handover rules, lives in the parent repository (repository root `AGENTS.md` and `.agents/docs/WORKFLOW.md`, four levels above this directory); this file only states how that policy applies to this small project. The completed checkpoint for this deliverable is [docs/tasks/done/done-0001-js-md-links.md](../../docs/tasks/done/done-0001-js-md-links.md), and the hardening evidence log is [HARDENING.md](../../HARDENING.md).
